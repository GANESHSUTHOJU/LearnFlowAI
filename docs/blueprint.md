# **App Name**: LearnFlowAI

## Core Features:

- Roadmap Generator: Generates personalized learning roadmaps using A* search, Beam Search, and Constraint Satisfaction based on learner goals and a skill ontology, with roadmap visualization and interactive exploration.
- Adaptive Quiz Coach: Implements a quiz and assessment module using Decision Trees and Reinforcement Learning, providing adaptive difficulty adjustments and personalized feedback with progress tracking. Employs an RL-powered tool that uses quiz history, skill graph structure and other assessment data to suggest a relevant question.
- Performance Predictor: Predicts learner performance, difficulty level, and dropout risk using Bayesian Networks, informing personalized interventions and adjustments to the learning path, displayed on an analytics dashboard.
- Chatbot Tutor: Provides a chatbot tutor for daily guidance and motivation, offering tips and answering questions related to the learner's current skill or project.
- Interactive Dashboard: Implements a sleek dark theme with glassmorphism UI, enhancing user experience with smooth transitions and engaging animations. Features an AI insights section highlighting key recommendations. Should contain 'Roadmap visualization and exploration' features.
- Progress and Analytics: Tracks learner progress and analytics using SQLite with RESTful API integration for efficient data management.
- Skill Catalog Navigation: Includes a comprehensive skill catalog with an intuitive navigation system for exploring available skills and learning resources.
- Full Integrated Backend: Full Integrated Backend with RESTful API to manage data and logic

## Style Guidelines:

- Primary color: Deep indigo (#4B0082) to convey intelligence and sophistication.
- Background color: Dark charcoal (#222222), a muted color of similar hue to the primary.
- Accent color: Teal (#008080) for highlights and interactive elements, creating contrast against the dark background.
- Premium color: Walnut Noir Gradient (linear-gradient(90deg, rgba(51,34,0,1) 0%, rgba(102,68,0,1) 50%, rgba(51,34,0,1) 100%)) for exclusive elements.
- Body text: 'Inter', sans-serif, for body text
- Headline font: 'Space Grotesk', sans-serif, a futuristic look for headlines.
- Use flat, line-based icons to maintain a modern and clean aesthetic.
- Incorporate subtle, smooth animations for transitions and user interactions to enhance engagement.
